# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-03-13

### Added

- Gain Control encoder action — adjust preamp gain with real-time LCD feedback
- Volume Control encoder action — control fader volume on any bus
- Phantom Power keypad action — toggle 48V per input channel
- Mute Toggle keypad action — toggle mute on any bus/channel
- OSC bridge with async command queue and bus state tracking
- Heartbeat polling for continuous state synchronization
- Property Inspectors for all actions
- LCD layouts for encoder actions
